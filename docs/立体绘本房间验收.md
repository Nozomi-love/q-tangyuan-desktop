# 立体绘本房间与全窗沉浸验收

本轮为本地源码升级，版本号仍为2.0.0。此前生成的EXE和GitHub截图不随源码自动变化。本次不修改养成数值、交易、存档或原始角色图片。

## 启动

先从托盘退出旧版进程，再在PowerShell运行：

```powershell
Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
.\.venv\Scripts\python.exe main.py --demo --dev-mode
```

独立演示档不会修改正式进度。正式玩家模式去掉 `--demo --dev-mode`；已有进程未退出时，双击只会唤醒原进程。

## 逐项体验

1. **小窝全景**：房间从内容区四边铺满；侧墙与后墙在约22%处转角，木地板向前展开，窗户能看到远山/树影及天空。查看书柜书本、茶壶、窗台的侧面和地毯厚度。
2. **前景案几**：在商城买几份食物回小窝；食品直接摆在木案几上，数量为小胶囊，点击投喂仍有飞行/咀嚼。食物较多时在案几上滚轮横向浏览；右侧木牌可直接去买粮。
3. **徽章导航**：底部是五枚独立短木牌，图上字下，悬停轻轻上浮。点击背包、商城、成长、设置，右侧抽屉展开时房间与汤圆仍可见。关闭抽屉恢复大场景。
4. **同屏换装装修**：在背包穿戴皇冠、调大小/高度、换地毯和房间主题；房间实时更新。依次缩放窗口至约820×650、1240×760和最大化，检查HUD、抽屉购买按钮、案几与徽章不重叠。
5. **昼夜**：开发设置的昼夜预览切换白天/夜晚/跟随系统。查看云朵、星光、窗框厚度、柔和斜光和悬尘；购买并布置暖心落地灯，直接点击灯罩测试墙地暖光。
6. **回位回归**：戳戳、连续赠礼后中断、原地空翻与绕屏；等待演出结束和回窝。汤圆应回地毯中心，放大皮肤/芝麻Buff与挂件也不改变静止脚底，桌宠固定位置不被房内镜头改变。

## 画师替换接口

参考 [房间图层规范](../assets/room_layers/README.md)。把有权使用的高清PNG放在 `assets/room_layers/`，用主题ID、家具ID或主题分层ID命名；已有PNG优先，缺失或无效图片继续使用矢量画面，不修改原图。角色始终使用已有动态渲染管线。

完整主题背景建议与窗口同宽高比；家具使用透明背景且裁掉多余空白，按文档的固定槽位自动等比适配。后续发布仅从允许的正式资源清单打包，个人试画不会自动发布。本轮未提供新的EXE包。

## 本机验证结果

- 667项全部通过：原有635项按独立进程分组（236/192/207），新增32项覆盖全窗布局、实际家具点击、透视、PNG优先和校验、缓存限制、时钟、极端缩放脚底与回位。
- Windows原生1240×760昼夜、同屏商城和820×650窄窗口截图均已目视检查，DPR1.5；正式与演示开发启动检查通过。
- 60帧整窗抓图CPU耗时：中位13.048ms、95分位17.566ms。此为本机绘制采样，不等同于屏幕实际呈现帧率或其他电脑性能保证。
- 61份源码通过Python3.10语法解析；运行仍在本机Python3.12.6/PySide6 6.8.3验证。原有105份PNG/ICO/WAV逐字节保持；核心养成、物理和存档配置未改。
- 验证未覆盖新的EXE包、另一台电脑或实体多屏。本轮未提交/推送GitHub。

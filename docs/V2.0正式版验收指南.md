# Q弹汤圆 V2.0 正式版全流程验收指南

本轮补齐衣橱、Lv.8～30目标与正式版工程体验，保留第一、二步的房间、礼物、音效、商城、成就、桌宠与旧存档。更新后先从旧版本托盘退出一次，再启动新版。

## 正式玩家模式

已有本机快捷方式可继续双击；源码启动：

~~~powershell
Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
.\.venv\Scripts\python.exe main.py
~~~

朋友无需安装Python：把本轮Windows x64便携ZIP完整解压，双击其中Q弹汤圆.exe。不要只复制EXE，不要直接在压缩包中运行。首次启动默认进入汤圆的家，关闭主窗收起到托盘，退出用托盘菜单。

1. 检查正式版右键/托盘没有“调试与外观”，设置不出现饥饿归零、收入结算、加速或等级跳转。关于卡显示“Q弹汤圆 v2.0 正式版”和实际数据目录。
2. 隐藏小窝与桌宠，再双击同一启动入口：已有进程唤出小窝与桌宠，进度不会重复加载或产生第二个存档写入者。不同演示档各自隔离。
3. 保留原有的名字、币、背包、成就、位置、静音与已选皮肤；食品仍只增加饱食度，礼物增加好感。所有功能抽屉保持房间可见。

## 开发者安全验收模式

~~~powershell
Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
.\.venv\Scripts\python.exe main.py --demo --dev-mode
~~~

终端输出本次独立演示save_data.json路径，正式存档不受影响。加速饥饿2秒/点、在线收入10秒一笔；建议需要看动画时先补满饱食。普通的main.py --dev-mode会使用真实进度，验收优先带--demo。

继续同一个演示档（替换成刚才实际输出的路径）：

~~~powershell
.\.venv\Scripts\python.exe main.py --resume-demo 'D:\Codex\Q弹汤圆\tests\artifacts\demo-实际时间\save_data.json' --dev-mode
~~~

进入成就与设置的设置页，底部有Lv.8/10/15/20/25/30快捷按钮：只向上升级，按正常升级结算奖励，实际改变当前演示档，便于验证每一阶段。装扮页“全部等级特权试用”也可快速体验挂件/特技；试用开关不保存。

## 衣橱：GIF、皇冠、空翻与独立记忆

1. 达Lv.3或花50币打开衣橱。选择换装与装修→皮肤衣橱→导入PNG/GIF；也可以导入带manifest.json的动作文件夹或ZIP。
2. 选文件后抽屉自动滚到导入预览。GIF持续播放，显示当前染色和挂件；房间原皮肤不变。取消保持原样，点“确认导入并穿戴”才写入衣橱和进度。
3. 皮肤卡片应显示各自真实idle贴图/首帧。可导入一张企鹅、一张其他角色比较，不能全是默认汤圆图标。
4. 选择GIF，在挂件装扮点皇冠，再到特技与等级奖励点原地空翻。GIF、呼吸、空翻、皇冠同步；也可叠加黑芝麻1.2倍或草莓染色。
5. 给皮肤A设0.70x与-20px，给皮肤B设1.50x与+25px。来回切换并退出重开，分别恢复各自设置。挂件高度在挂件页，大小在衣橱页。
6. 点重命名，卡片立即更新且重启保留。点“移入回收区”会切回默认外观并收起该卡；点击回收区卡片可还原，原素材与独立配置保留，不物理删除图片。

原导入限制继续有效：PNG/GIF单文件20MB，最长边8192且1600万源像素，GIF最多200帧/累计6400万像素；ZIP路径、链接、压缩率与总大小均校验，纹理缩至512px。素材仅留本机，预览也不上传。

## 备份、恢复与版本更新

1. 成就与设置→设置→数据安全与关于，核对版本和本地目录。
2. 点一键备份，选择一个新的ZIP文件名；备份包含当前存档、有效的本地导入皮肤及SHA-256校验索引。
3. 更改名字、穿戴、房间布置等后，选择原ZIP恢复并确认。当前进度先自动备份，随后界面、GIF、独立配置、家具和静音立即恢复。
4. 同ID但素材或元数据不同会生成新皮肤ID，保留当前本地原件；校验失败不替换存档。恢复不清理已有皮肤，回收区也可继续还原。
5. 源码版继续使用项目data/save_data.json与assets/skins；V2.0 EXE正式版使用系统AppLocalDataLocation固定目录（以设置显示的绝对路径为准）。同一账户把新版解压至新目录，正式版进度仍接续；旧EXE目录有data存档时首次升级会安全迁移并保留原件。
6. 换电脑或源码/EXE之间切换：在旧版导出备份，在新版恢复即可。程序安装ZIP可发朋友，个人进度备份含私人素材，请自行保管。

# 项目目录说明

根目录：D:\Codex\Q弹汤圆。

按职责可以理解为 8 个部分。目录数量和职责数量不同，例如运行环境这一类包含 .venv、.runtime_tmp、__pycache__ 三个目录。

| 部分 | 位置 | 当前职责 |
| --- | --- | --- |
| 1. 核心程序 | 根目录的五个 .py 文件 | 应用启动、养成模型、宠物物理/渲染、窗口/气泡与存档 |
| 2. 图片素材 | assets/ | 当前四张汤圆原图、状态映射；挂件和图标目录预留 |
| 3. 界面样式 | styles/ | theme.qss 控制柔和菜单样式，后续扩展到主面板 |
| 4. 配置与数据 | config/、data/ | config/catalog.json 保存计时和白砂糖数值；data 保存窗口与完整养成进度 |
| 5. 验证测试 | tests/ | 回归测试、真实素材检查、Windows 原生检查、跨进程重启检查 |
| 6. 项目文档 | README.md、docs/ | 使用说明、项目规范、开发过程、素材来源和本说明 |
| 7. 运行环境 | .venv/、.runtime_tmp/、__pycache__/ | Python 与依赖、安装临时内容、Python 字节码缓存 |
| 8. 版本与协作 | .git/、.gitignore、AGENTS.md、*.bak.* | Git 历史、忽略规则、协作授权和历史备份 |

## 五个核心文件

- main.py：入口和应用控制器。创建桌宠、托盘和右键菜单，连接操作信号，协调模型、自动保存、升级反馈和退出。
- models.py：养成模型。饥饿、经验升级、币、每日掉落、累计统计、挂机礼包、摸头冷却，通过 Qt 信号通知界面。
- pet_engine.py：动作与外观。包含状态、呼吸、果冻弹簧、拖拽倾角、重力、碰撞、固定开关、图片加载和绘制。
- pet_window.py：桌面窗口。接收鼠标、区分点击/拖拽、适配显示器与 DPI、调度画面更新，管理独立气泡，并提供位置捕获/恢复接口。
- save_manager.py：本地 JSON 存档。统一读写养成数据和位置，迁移备份、校验、原子写入、并发保护与未知字段保留。

目前已有 models.py；dashboard.py 将在 Phase 3 加入，保持六个核心模块以内。五个核心文件均包含实际功能。

## 常见修改入口

- 调整养成、收益、升级公式与每日限制：models.py；计时和白砂糖数值优先改 config/catalog.json。
- 调整重力、回弹、呼吸、体型：pet_engine.py。
- 调整拖拽、桌面窗口或气泡行为：pet_window.py。
- 添加托盘/右键菜单：main.py。
- 更换当前表情：assets/skins/default/ 和 expressions.json。
- 修改菜单配色、圆角、字体：styles/theme.qss。
- 查看已完成内容与测试依据：README.md、docs/开发日志.md。
- 检查本地养成和固定位置：data/save_data.json；程序退出后查看，避免与自动保存并发编辑。

依赖、缓存、Git 元数据和备份通常无需手动修改。完整文件保护规则继续适用；本说明不授权删除任何文件。

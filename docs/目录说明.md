# 项目目录说明

[项目首页](../README.md) · [开发指南](开发指南.md)

当前对外版本为 2.0.0。九个根目录 Python 模块通过共享模型与信号槽连接小窝、桌宠和托盘。

| 文件 | 职责 |
| --- | --- |
| main.py | 参数、应用身份、模型与双窗口、托盘、事件连接、自动保存与安全退出 |
| models.py | 饱食、好感、币、交易、背包、Buff、家具、成就和特权；唯一结算入口 |
| pet_engine.py | 共享物理、状态、形变、PNG / GIF 帧、染色、挂件与特技 |
| pet_window.py | 透明桌宠、输入、工作区、位置、气泡、飘字与程序化音效 |
| dashboard.py | 小窝、HUD、喂养架、导航、同屏抽屉、衣橱与设置 |
| home_scene.py | 房间、家具、光影、日常、礼物、食物飞行与咀嚼，只读组合姿态 |
| illustrated_assets.py | 87 张插画生成与加载、同名本地图保护、可见文字清理 |
| save_manager.py | JSON 校验迁移、原子写入与并发保护；内置皮肤与旧个人素材兼容（已无导入界面） |
| release_support.py | 版本、稳定数据目录、单实例与带校验的备份恢复 |

```text
q-tangyuan-desktop/
├── 九个核心 Python 模块
├── README.md                       # 项目首页
├── AGENTS.md                       # 协作约定
├── requirements.txt                # 运行依赖
├── requirements-build.txt          # Windows 构建依赖
├── config/catalog.json             # 商品、家具、等级、成就与计时
├── styles/theme.qss                # HUD、卡片、抽屉和菜单样式
├── assets/
│   ├── icons/tangyuan.ico          # 软件、任务栏、托盘图标
│   ├── item_icons/                 # 87 张可替换 80px 插画及映射表
│   ├── sounds/                     # 五种本地音效
│   ├── accessories/                # 挂件扩展位，当前主要由 QPainter 绘制
│   └── skins/
│       ├── default/                # 四张原图与 expressions.json
│       ├── teams_s16/              # 八款正式队标PNG与manifest，随仓库发布
│       └── user_<id>/              # 旧个人素材兼容，不提交
├── data/save_data.json             # 源码模式进度，不提交
├── tools/
│   ├── build_windows.py            # Windows x64 便携包构建
│   ├── windows_version.txt         # EXE 文件 / 产品版本
│   └── licenses/                   # 第三方许可
├── docs/                           # 现行指南、截图与历史记录
├── tests/                          # 自动化和 Windows 原生检查
│   └── artifacts/                  # 本地证据，不提交
└── releases/                       # 本地构建，不提交
```

`.venv/`、`__pycache__/`、`.runtime_tmp/` 是本机环境与工作缓存，不是玩家资源。EXE 正式数据位于稳定系统应用数据目录，路径见设置；源码使用项目 data 与 skins，演示使用隔离 artifacts 目录。

个人皮肤、存档、备份、导入预览、本机快捷方式与二进制不进入 Git。跨电脑或源码 / EXE 迁移用软件内备份恢复。

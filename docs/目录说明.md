# 项目目录说明

根目录：D:\Codex\Q弹汤圆。

按职责可以理解为 8 个部分。目录数量和职责数量不同，例如运行环境这一类包含 .venv、.runtime_tmp、__pycache__ 三个目录。

| 部分 | 位置 | 当前职责 |
| --- | --- | --- |
| 1. 核心程序 | 六个业务 .py + 两个渲染 .py | 应用启动、养成/商城/成就/特权模型、物理/分层渲染、窗口/气泡、存档/皮肤沙箱与主面板 |
| 2. 图片素材 | assets/ | 默认四张汤圆原图与状态映射；`user_<uuid>/` 存本地导入皮肤；挂件由代码矢量绘制 |
| 3. 界面样式 | styles/ | theme.qss 控制小窝HUD、喂养架、底部导航、抽屉、装扮子标签、菜单与挂件样式 |
| 4. 配置与数据 | config/、data/ | config/catalog.json 保存七食物 / 四礼物及三级配置、互动台词、永久特技商品、Buff、12款家具、十二成就、六级奖励路线、计时和交互阈值；data 保存完整进度 |
| 5. 验证测试 | tests/ | 回归测试、真实素材检查、Windows 原生检查、跨进程重启检查 |
| 6. 项目文档 | README.md、docs/ | 使用说明、项目规范、开发过程、素材来源和本说明 |
| 7. 运行环境 | .venv/、.runtime_tmp/、__pycache__/ | Python 与依赖、安装临时内容、Python 字节码缓存 |
| 8. 版本与协作 | .git/、.gitignore、AGENTS.md、*.bak.* | Git 历史、忽略规则、协作授权和历史备份 |

## 六个业务文件与两个渲染模块

- main.py：入口和应用控制器。创建桌宠、托盘和右键菜单，连接操作信号，协调模型、自动保存、升级 / 特权反馈、导入 / 切换外观、特技与退出。
- models.py：养成模型。饱食度、升级、币、食物 / 赠礼 / 库存 / 永久特技购买、限时风味、成就/称号、每日掉落、等级解锁、挂件选择 / 偏移和累计统计，通过 Qt 信号通知界面。
- pet_engine.py：房间、动作与外观。RoomCanvas绘制昼夜房间、五槽家具、食盆反馈和房间气泡，映射共享宠物动画，不重复推进物理。包含状态、呼吸、果冻弹簧、拖拽倾角、重力、碰撞、固定开关、PNG / GIF 统一变换、独立挂件、空翻 / 分身 / 弹力球 / 四边绕屏滚动及分层绘制。
- pet_window.py：桌面窗口。接收鼠标、区分点击/拖拽、适配显示器与 DPI、调度画面更新，管理独立气泡，并提供位置捕获/恢复接口。
- save_manager.py：本地 JSON 存档。统一读写版本5养成/背包/称号/成就/Buff、皮肤ID / 挂件 / 已购特技与位置，迁移备份、校验、原子写入、并发保护与未知字段保留；同文件中的 SkinManager 管理安全导入、ZIP / manifest 校验、沙箱复制和模板导出。
- dashboard.py：主产品小窝。顶部常驻HUD/命名/桌宠显隐，中部房间，下部喂养架和五项导航；状态背包、商城、成就、装扮、设置、家具作为抽屉。商城含食物/礼物和家具，装扮仍分三个子页；共用模型，关闭隐藏、托盘双击唤出。

六个核心模块已齐备且均有实际功能。Phase 4 在现有结构内接入等级特权、独立挂件、通用特技与本地用户皮肤，当时没有新增第七个模块。2026-10-18用户明确要求独立插画和场景模块，现新增以下两文件：

- illustrated_assets.py：67张80px插画的生成、PNG优先加载、同名本地图保护与显示文字过滤。
- home_scene.py：统一暖棕描边/投影/昼夜光照的游戏房间、侧边食盆茶几、大宠物/HUD边界适配、RoomLife自主日常、四礼物专属演出、食物飞行/咀嚼/实际增量飘字。只读姿态组合共享引擎，不另推进桌面物理。

## 常见修改入口

- 调整养成、收益、升级公式与每日限制：models.py；商品、Buff、成就、等级路线和阈值优先改 config/catalog.json。
- 调整重力、回弹、呼吸、体型、挂件矢量图和特技：pet_engine.py。
- 调整拖拽、桌面窗口或气泡行为：pet_window.py。
- 添加托盘/右键菜单：main.py。
- 更换默认表情映射：assets/skins/default/expressions.json；个人皮肤优先从主面板导入，不覆盖默认原图。
- 调整导入限制、manifest校验、沙箱复制与存档升级：save_manager.py。
- 修改小窝HUD、抽屉、导航与装扮子页布局：dashboard.py；修改菜单/面板配色、圆角、字体：styles/theme.qss。
- 查看已完成内容与测试依据：README.md、docs/开发日志.md。
- 检查本地养成和固定位置：data/save_data.json；程序退出后查看，避免与自动保存并发编辑。

依赖、缓存、Git 元数据和备份通常无需手动修改。完整文件保护规则继续适用；本说明不授权删除任何文件。

用户导入素材只保存在 `assets/skins/user_<uuid>/`，没有网络上传接口；Git 忽略这些目录。挂件不是画死在默认图片上，而是附着于统一外观变换后的独立图层，所以默认四图、单张 PNG 与动态 GIF 共用同一套装扮和特技。

当前UI全部使用本地插画；五导航和同屏抽屉布局以Phase5A验收.md为准。房间在home_scene.py，绘制资产在illustrated_assets.py；替换大图标按assets/item_icons/README.md的ID，不覆盖默认宠物原始四图。

## Windows便携分发（2026-10-18）

- tools/build_windows.py：全新目录构建PyInstaller目录版及ZIP，只收集内置资源，拒绝玩家档和user_*皮肤；不清空旧构建。
- requirements-build.txt：仅开发者打包依赖，朋友无需安装。
- tools/licenses/：Qt官方LGPL/GPL许可原文，随便携版分发；Python许可从当前构建解释器原件读取。
- releases/：每次构建的便携目录、ZIP、清单和构建缓存，全部Git忽略。
- tests/test_phase5_distribution.py、tests/verify_distribution_native.py：分发边界、Windows任务栏身份、真实ZIP移位启动检查。
- docs/自定义皮肤与便携版.md：PNG/GIF/多状态包格式与朋友使用指南。
- assets/icons/tangyuan.ico：桌面快捷方式、窗口、托盘和EXE的同一份软件图标。

# 项目规范与阶段路线

## 产品约束

《Q弹汤圆》是本地离线运行的桌面宠物容器与免费养成游戏。默认汤圆外观使用四张表情图片；渲染内容与坐标/旋转/形变分离，使以后上传的 PNG/GIF 也能复用动作、挂件和特效。

桌宠窗口透明、置顶、无边框、不显示任务栏主窗口按钮；养成主窗口为可视化汤圆小窝，HUD常驻、房间互动、喂养架及五项底部导航；背包、商城、成就、装扮、设置、家具使用抽屉，装扮仍有三个子页。系统托盘提供唤出、复位、主面板、静音与安全退出；后续功能按阶段接入。

## 养成规则

- 饥饿 0～100 随时间衰减，归零只饿扁至约 40% 高度，不死亡、不扣好感；喂食后恢复。
- 好感 Lv.1～Lv.30，只增不减。当前规则：饥饿 ≥50 的戳戳 +2 EXP，否则 +1；每级所需 EXP=当前等级×500（原值的10倍，已有等级和经验保留），升级 +30 币，满级停止积累经验。食物不增加经验，三级礼物分别+20/+80/+240 EXP；摸头和挂机礼包仍按自身规则增加经验。
- 糯米币来自在线自动入账、每日互动和一次性成就奖励。2026-10-17更新：在线每90秒直接获得10～20币 / 5 EXP，不显示拾币气泡，无需点击或等待超时；开发加速为10秒。未来正式版可另调至 10 分钟，当前不启用。每天前 20 次戳戳各以 35% 概率 +2 币。
- 初始 100 币 / 饥饿 80 / Lv.1；正常在线每 288 秒饱食度 -1，满值到0共8小时，不补算离线惩罚或收益。白砂糖 -10 币 / 饱食度 +15 / 无好感收益；摸头 +3 EXP，冷却 10 秒。
- 商城使用游戏代币，包含三级食物与三级礼物；七食物按级恢复15/35/65，价格10/25/45币；折纸星星、小花束、八音盒价格20/70/180币。食物风味、等级赠送的饰品/玩具仍可使用。
- Phase 3 最新风味：黑芝麻灰色/1.2倍、草莓粉色/光点、抹茶绿色、辣油红色。普通风味持续60秒，开发加速下新风味15秒；辣油行为前12秒，自由模式当前任务栏小跑轻跳，固定模式不移动锚点，仅原地跺脚。同类刷新、不同风味替换，保留Alpha和五官。
- 等级奖励包括通用坐标动作、独立图层饰品/粒子和系统特权。双击用于主面板，空翻走独立菜单。
- Phase 3 三阶十成就以最新指令为准：新手（点击1、抛落1、投喂1、摸头1），进阶（三口味、礼包3、Lv.3），隐藏（5秒15次独立点击、快速左右摇晃、真实饿扁后喂食）。达成后播报、手动领取一次性币与称号奖励。
- 双击使用200ms窗口并取消待确认单击收益；主面板关闭仅隐藏，程序退出必须放行。保存背包、未领/已领成就、称号、体验口味与Buff在线剩余时间，兼容旧档及独立演示。
- 存档统一为本地 save_data.json，包含代币、饥饿、好感/经验、背包、成就、穿戴、皮肤选择；不提交玩家存档到 GitHub。

## 工程约束

Python 3.10+、PySide6，QPainter 统一渲染，QMovie 按当前帧接入统一变换。模型、持久化与窗口分离，使用信号槽通信。每阶段交付完整可运行文件，不留核心逻辑空实现。界面使用统一柔和 QSS。

桌面位置使用 Qt 逻辑像素，按当前显示器工作区计算地面，处理高 DPI、负坐标与工作区变化。测试报告区分实际设备验证与模拟情况。

## 四阶段

1. Phase 1：桌宠窗口、默认外观、呼吸/回弹/拖拽/重力/落地、基础托盘。
2. Phase 2：存档、饥饿/饿扁、好感升级、气泡与快捷菜单、代币来源。
3. Phase 3：四页主面板、商城、背包、限时 Buff、三阶成就。
4. Phase 4：等级奖励、独立挂件、通用空翻、PNG/GIF 导入及 manifest.json 动作包。

Phase 3 已由用户验收。Phase 4 在既有六模块内完成等级奖励、向量挂件、程序化特技与本地皮肤衣橱。Lv.2嫩芽/空翻；Lv.3皇冠/导入，50币可提前开放导入；Lv.4热气/分身；Lv.5墨镜/芝麻弹力球；Lv.6蝴蝶结/【阿一古】，好感上限仍为30。

挂件有head/face/effect三槽及-30～+30逻辑px偏移，绑定皮肤主体相对包围盒，使用同一形变/旋转/位移管线。特技走右键子菜单与装扮的特技子页：空翻1.1秒/5秒冷却/+5EXP、分身2.5秒、弹力球5秒；互斥，固定时锚点不移动，真实或测试饿扁/被拖拽/空中下落暂不可发动。

只有以--dev-mode启动的进程可勾选全特权调试，不由普通计时加速开关提权。调试开关为运行期，等级/经验不虚构；调试获得的荣誉称号及实际互动统计记入当前存档，建议只用--demo。关闭试用后挂件按真实等级重新门控，当前自定义皮肤仍可在下次启动恢复。

皮肤导入支持PNG/GIF、文件夹与ZIP，manifest包含schema_version=1/name/author/remove_white_background/states，idle必填。复制后素材仅在assets/skins/user_<32hex>/沙箱，当前ID和挂件保存到版本5存档。QMovie CacheNone、单帧缩放512，PNG可在内存去除边缘连通白色；原素材不变。包内代码不执行，不上传任何自定义素材，Git忽略所有user_*目录。

安全预算：单文件20MB、ZIP64项/展开总量64MB，异常压缩率/加密/重复大小写/绝对路径/../设备名/链接/重解析点拒绝；源边长8192及1600万像素上限，GIF最多200帧/累计逻辑画布6400万像素，严格检查帧块和完整结束标记。首次切换与热重载均检查真实路径。模板只新建目录和文件。

新增二阶成就《灵魂注入》：首次导入/切换自定义皮肤或穿戴挂件；100币与【百变星君】需手动领取一次。成就总数11，三阶数量4/4/3。版本1～4迁移5先原字节备份，保留窗口/养成/未知字段；未达等级不抹除已有挂件选择，实际绘制过滤权限。验收详见Phase4验收.md。

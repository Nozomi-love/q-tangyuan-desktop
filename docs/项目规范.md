# 项目规范与阶段路线

## 产品约束

《Q弹汤圆》是本地离线运行的桌面宠物容器与免费养成游戏。默认汤圆外观使用四张表情图片；渲染内容与坐标/旋转/形变分离，使以后上传的 PNG/GIF 也能复用动作、挂件和特效。

桌宠窗口透明、置顶、无边框、不显示任务栏主窗口按钮；养成面板包含状态与背包、免费商城、成就图鉴、自定义皮肤与设置四页。系统托盘提供唤出、复位、主面板、静音与安全退出；后续功能按阶段接入。

## 养成规则

- 饥饿 0～100 随时间衰减，归零只饿扁至约 40% 高度，不死亡、不扣好感；喂食后恢复。
- 好感 Lv.1～Lv.30，累计经验只增不减。饥饿大于 50 时，投喂、互动与陪伴可加经验。
- 糯米币来自挂机拾币气泡、每日互动和一次性成就奖励。测试挂机周期 1 分钟，正式周期 15 分钟。
- 商城使用游戏代币，包含基础食物、限时风味 Buff、永久饰品/玩具。
- 黑芝麻糊：深灰染色与 1.2 倍体型，3 分钟；草莓果酱：粉色 3 分钟；辣油：泛红并加速跑动 10 秒。
- 等级奖励包括通用坐标动作、独立图层饰品/粒子和系统特权。双击用于主面板，空翻走独立菜单。
- 成就三阶：新手（首次点击、抛落、购买投喂）、进阶（首次风味 Buff、首次导入皮肤）、隐藏（5 秒内点击 20 次）。
- 存档统一为本地 save_data.json，包含代币、饥饿、好感/经验、背包、成就、穿戴、皮肤选择；不提交玩家存档到 GitHub。

## 工程约束

Python 3.10+、PySide6，QPainter 统一渲染，QMovie 预留 GIF 接入。模型、持久化与窗口分离，使用信号槽通信。每阶段交付完整可运行文件，不留核心逻辑空实现。界面使用统一柔和 QSS。

桌面位置使用 Qt 逻辑像素，按当前显示器工作区计算地面，处理高 DPI、负坐标与工作区变化。测试报告区分实际设备验证与模拟情况。

## 四阶段

1. Phase 1：桌宠窗口、默认外观、呼吸/回弹/拖拽/重力/落地、基础托盘。
2. Phase 2：存档、饥饿/饿扁、好感升级、气泡与快捷菜单、代币来源。
3. Phase 3：四页主面板、商城、背包、限时 Buff、三阶成就。
4. Phase 4：等级奖励、独立挂件、通用空翻、PNG/GIF 导入及 manifest.json 动作包。

# V2 第二步验收：汤圆的日常与互动演出

本轮交付随机自主日常、四种礼物的房间演出、投喂抛物线/三次咀嚼/粒子、实际收益飘字和四款程序合成音效。第三步的单皮肤偏移、Lv.7～30长期目标与正式版收尾尚未开始。

## 启动独立体验

先从托盘退出旧版本，再在 PowerShell 运行：

    Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
    .\.venv\Scripts\python.exe main.py --demo --dev-mode

此命令创建新的演示存档，不影响正式玩家数据。启动后默认回小窝。正式体验可双击既有桌面快捷方式，或运行 main.py；本轮更新的是源码，历史便携ZIP不会自动变成新版。

## 1. 自主日常与打断

- 小窝保持可见、不要点击：正常模式静置12～25秒后随机启动闻饭、看窗、打盹、哼歌或小跳，完成后重新等待。开发加速下等待2～4秒；有礼物时还可能凑近看看。不是每次固定顺序。
- 想立即看指定动作：底部“成就与设置”→“游戏设置”，向下滚到“房间日常预览（仅开发模式）”，依次点“去看看窗外”“打盹与伸懒腰”“去茶几闻一闻”“摇晃哼歌”“开心小跳”。房间一直在旁边可见。
- 打盹有轻微压扁、眯眼开心差分与上升zZ，约5秒后伸懒腰、回弹；哼歌有绘制的音符，小跳有清晰上下位移。默认/自定义皮肤统一使用共享表情与变换管线。
- 闻饭前把饱食降至50以下，更容易看到想吃东西的台词；看窗台词随电脑时间区分云朵/月亮。日常对白低频出现，深夜提醒休息、饭点提醒吃饭；连续预览不会挤掉当前用户对白。
- 动作中戳戳、右键摸头、投喂，或拖动已显示的桌宠：立即优先响应输入，自主姿态短时平滑回正，不把房间移动写入桌宠坐标。饿扁/眩晕/显式特技也优先。隐藏小窝暂停本地日常，不补算离线动作。

## 2. 陀螺与八音盒

- 无需攒钱的演出预览：同一开发设置区下方有“试玩陀螺”“试听八音盒”“看看折纸星星”“闻闻花束”，仅预览，不扣币、不加经验、不增加赠礼统计。
- 真实消费：商城→食品与礼物→礼物。陀螺、八音盒各180糯米币，赠送各增加240好感；可购买后在背包赠送，也可“购买并赠送”。演出约7秒，收益只结算一次。
- 陀螺有彩色旋转盘面、运动残影和地板漂移；汤圆靠近后约2.6秒轻碰，陀螺加速弹开，出现专属吐槽。
- 八音盒打开，机芯转动，彩色音符不断升起；汤圆随节拍摇摆，播放一段原创轻柔琶音。折纸星星环绕闪动，小花束有凑近闻花与飘落花瓣。
- 连续赠礼按队列展示；所有演出不重复扣币/库存或加经验，已固定的桌宠不会跟着房内汤圆移动。

## 3. 投喂、收益与音效

- 用商城“购买并投喂”、背包“投喂”、底部喂养架分别投喂一次：插画从对应入口飞入房间，约0.78秒抵达汤圆嘴边，随后0.9秒内连续三次咀嚼，并迸发6颗绘制的心形/星形粒子。
- 饱食度实际只差3点时投喂，飘字只显示“+3 饱食度”；满饱不虚报恢复。食物仍不增加好感，礼物/摸头/戳戳增加实际好感；满级不显示不存在的经验。
- 戳戳时可见好感飘字；前20次的随机掉币、在线自动入账、升级及领奖也显示实际糯米币增量。文字用深棕描边、按饱食/好感/币区分颜色，上浮1.2秒后渐隐；不重新启用拾币对话气泡。
- 可在开发设置点击“结算在线收入”立即验证收益和叮当音。真实消费增加的好感跨级时，升级奖励的30币单独显示，购买花费不当作正收益。
- 四音效：戳戳的水滴音、抵达后咀嚼双音、收益/成就叮当音、八音盒旋律。均为本机标准库合成的PCM WAV，不依赖外部录音。
- 右上HUD八音盒小按钮是音效开关，悬停会提示；按下高亮表示静音。右键桌宠与托盘共用同一“静音”菜单项，操作任一处其它位置立即同步。静音会停止当前旋律。
- 静音后从托盘退出，用同一份演示存档恢复：

    .\.venv\Scripts\python.exe main.py --resume-demo '终端打印的实际save_data.json路径' --dev-mode

应仍为静音。旧存档没有muted字段时默认开启音效；字段是严格布尔值，版本仍为5。实际听感与系统音量、输出设备有关，音效不可用时养成/存档/动画继续运行。

## 自动检查

    .\.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -p 'test_phase*.py'
    .\.venv\Scripts\python.exe -B -X utf8 tests\verify_v2_step2_native.py

测试使用独立沙箱；截图、报告和测试存档保留在tests/artifacts/，不上传。Windows原生检查会临时打开测试窗口并短暂播放音效，随后自行退出。新增用例覆盖随机区间/行为多样性、平滑打断、陀螺只碰一次、实际收益跨级/满饱/满级边界、三入口投喂与三次咀嚼、音效PCM/不覆盖/降级/静音和存档恢复。原生检查另外验证四个QSoundEffect真实解码、播放、150% DPI，以及两个独立进程恢复静音、GIF、家具和进度。

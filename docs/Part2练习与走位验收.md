## 推荐验收顺序

1. **商城与背包**：进入“商城 → 食品与礼物”的食物/礼物分类，购买各一份，回“背包 → 投喂与赠礼”使用；在换装或家居家具分类购买两件挂件、主题与岩壁。检查库存、价格、永久拥有及售罄/已拥有状态，重复操作不重复扣款。
2. **礼物三种演出**：分别使用练习册、沙漏、击拳手套。手套出现后点击伸出的手套区域，观察碰拳；第二次完全不点，确认仍自动完成且奖励相同。点汤圆本体或投喂可以中断旧演出，不能留下地面手套/沙漏/练习本。
3. **泡面与夜宵**：先调低演示档饱食度，再用快捷投喂架、背包或商城快捷使用各测一次；观察图标飞入、咀嚼和3秒专属小演出。确认食品只恢复饱食、不增加好感。
4. **四槽挂件**：在“背包 → 换装 → 挂件”装备七号护目镜和围巾，皇冠/周身特效仍可同穿。戳一下看镜片短光；显示桌宠并拖拽检查围巾滞后。换皮肤、大小或挂件高度后检查位置与边界，既有PNG不被重写。
5. **训练主题与岩壁**：在“背包 → 装修”布置加练训练室，使用练习礼物看本组计次；墙面改为登峰岩壁后使用既有登山镐，观察岩点逐级亮起和路标。装备登峰小背包可增强组合小旗，平常家具无被动金币音效。
6. **反向闪现**：商城特技分类购买后，从“背包 → 特技”或桌宠右键特技菜单发动。自由桌宠在当前工作区安全短闪，屏边自动缩短；固定桌宠本体脚底与窗口位置保持，只出现局部残影。房间使用独立安全区，不套用桌面的全局偏移。冷却未结束/真实饿扁/拖拽等拒绝不扣款、不启动新冷却。
7. **中断与回窝**：从地毯外的位置开始礼物或反向闪现，分别点击、摸头、投喂、拖拽、换另一特技、隐藏再唤醒、换皮肤。检查当帧脚底连续、所有临时箭头/残影/道具清场；自然末帧回本次起点，继续观察0.5秒、1.5秒及足够回地毯的时刻，最终HOME_X=0.48。固定桌宠存档锚点不能被房间动作改写。
8. **重启恢复**：买好两挂件、两家具与特技并穿戴布置，保存退出；用打印的演示存档路径重开。检查库存、所有权、四槽选择、主题/岩壁及称号保留；正在播放的临时道具不会跨重启重播。

## 两个原创称号

- **这次真练好了**：成功消费使用纳尔练习册与加练沙漏各一次，并真实点击一次已布置的训练假人。三个体验顺序不限，进度保存在本地；仅购买、开发预览、点击未布置假人不计。小纳尔耳帽可加强练习册组合视觉，不是称号必须条件。
- **登峰造圆**：先布置登峰岩壁，再成功使用登山镐。登峰小背包增强小旗表现，不是获得称号的前提。

称号按模型成功接受操作一次授予，中断演出不再重复扣库存、加经验或重授称号；演出完成与击拳点击没有第二份资源奖励。获得后到“背包 → 换装 → 称号”佩戴。

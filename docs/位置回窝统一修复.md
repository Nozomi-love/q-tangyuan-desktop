# 房间与桌宠的位置回位修复

本轮继续保留本地，未更新GitHub或便携EXE。此前修复验证了动作结束当帧的起点；本轮补齐被打断后的整个回窝过程和实际绘制坐标。

## 修复内容

- **房间不再停在茶几旁**：用户操作后先在当下位置响应，静置约1.5秒，再平滑回到地毯。回窝独立于12～25秒的随机活动计时；饿扁、眩晕也不会无限阻止回窝。正常大小下通常在结束/中断后约4～6秒回到地毯。
- **表情与位置解耦**：开心表情、升级和房间自己发出的打盹表情不再误取消散步或回程。真正点击、摸头、投喂和拖拽仍优先响应。
- **渲染位置一致**：放大缩小围绕当前脚底，避免把闲逛位移额外乘上角色放大比例；房间不再继承桌面抛落/拖拽的绝对高度。戳戳轻跳使用房间本地时钟，显式特技仍共享皮肤、表情、形变与特技状态。
- **礼物/特技收尾**：十件礼物、五个特技、家具互动先结束自身演出并恢复起点，随后回地毯。主动打断会清除尚未播放的旧礼物队列，旧演出不能稍后重新移动角色；不会重复结算或倒扣已经获得的好感。
- **辣油收尾**：奔跑首尾的横向幅度平滑收束；奔跑时不额外开启闲逛，结束后走回地毯。
- **桌面位置记忆**：固定切换和恢复位置结束旧特技，显式放置清除旧回弹；靠边回弹时保存静止锚点，避免把临时让边的位置写成永久位置。桌宠仍尊重用户固定位置和真实抛投，房间回窝不会把桌宠送回屏幕右下角。

## 本地验收

先从托盘退出旧程序，避免二次启动只是唤醒旧进程。

```powershell
Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
.\.venv\Scripts\python.exe main.py --demo --dev-mode
```

1. 用设置里的日常预览让汤圆去茶几/窗边，途中戳它、摸头、喂食或开抽屉；应当先原地响应，随后回地毯，不会永久卡边。
2. 在侧面送花束、弹力绳等，等演出结束；再测试连送两件后戳一下。旧礼物不能重启并把它拉走。
3. 在侧面发动空翻、分身、球、绕屏和蹦迪；分别等待完成和途中打断，确认当帧无跳位、最终回窝。
4. 在侧面调试饿扁或戳到眩晕，再等几秒；位置可回窝，体型/表情按实际状态保持，喂食恢复不应改变脚底位置。
5. 切换大小、挂件、风味、抽屉宽度及窗口大小，再还原；确认实际脚底回到同一地毯位置。把桌宠拖高也不应把房间里的汤圆长期吊在半空。
6. 将桌宠取消固定放在屏幕两边，戳它回弹时退出重启；再测试特技中切换固定、重置位置。桌宠恢复自己的屏幕位置，房间恢复自己的地毯位置。

开发模式日常间隔较短，回窝后再次出门属于新的活动。需要慢慢观察时关闭开发测试加速模式；不要把新的探索误认为上一次没有回位。

## 我应该导入什么文件

最简单的是一张静态PNG或一张动态GIF，不必同时准备四张表情。

| 文件 | 适合用途 | 建议 |
| --- | --- | --- |
| PNG | 静态角色或表情包 | 透明背景，主体居中，长边256～512px比较清晰 |
| GIF | 会自己动的表情包 | 最好透明背景、循环播放，画面不要频繁改变角色位置 |
| 文件夹或ZIP | 待机、开心、眩晕、饿扁各有不同表情 | 内含manifest.json和它引用的PNG/GIF |

操作：进入「换装与小窝装修 → 皮肤衣橱」，点击导入本地图片/GIF。Lv.3免费解锁，或花50糯米币提前解锁。PNG若是纯白底，可打开「自动移除纯白背景」图形开关。这里的导入是本机复制，不会上传服务器。

单文件不超过20MB。源图片最长边不超过8192px、总像素不超过1600万；导入后的渲染纹理自动等比限制到512px。GIF最多200帧、各帧源画布像素累计不超过6400万，因此短循环更合适。JPG、WebP、视频和可执行文件当前不能直接作为皮肤导入。

尽量裁掉大面积空白。制作多状态包时，让各张图使用相同画布、相近角色位置和一致的脚底位置，挂件和状态切换会更稳定。挂件高度也可以在装扮页微调。

### 多状态包示例

    我的皮肤/
      manifest.json
      idle.png
      happy.gif
      dizzy.png
      flat.png

manifest.json内容：

~~~json
{
  "schema_version": 1,
  "name": "我的小伙伴",
  "author": "你的名字",
  "remove_white_background": false,
  "states": {
    "idle": "idle.png",
    "happy": "happy.gif",
    "dizzy": "dizzy.png",
    "flat": "flat.png"
  }
}
~~~

idle必填，其余状态可省略，会回退到idle。路径必须是包内相对路径，不能用绝对路径或..。可以直接导入这个文件夹，或把整个文件夹压成普通ZIP后导入。省事的方法是先点击「导出皮肤包模板」，再替换模板里的图片。

给GIF戴皇冠并空翻：导入GIF → 在挂件装扮页点皇冠 → 在特技页点原地空翻。达到对应等级或在开发演示中启用全部等级特权试用后即可操作。GIF本身动效会与空翻、呼吸、染色等通用变换叠加。

## 发给不会安装Python的朋友

使用releases目录中本轮构建的「Q弹汤圆-Windows-x64-时间.zip」，发整个ZIP即可；不需要发送源码、虚拟环境或自己的存档。

朋友操作：

1. 将ZIP完整解压到有写权限的普通文件夹。
2. 双击其中「Q弹汤圆/Q弹汤圆.exe」。不要只拷贝EXE，也不要在压缩包预览里直接运行。
3. 关闭小窝会收起到托盘；真正退出请右键托盘选择「退出程序」。
4. 想做桌面图标时，可右键EXE创建快捷方式。

这是面向Windows x64的便携文件夹版本，不是macOS/手机安装包。运行依赖与解释器已在包内。存档首次运行生成在EXE同目录data/save_data.json，自定义皮肤在assets/skins/user_*/；换电脑时退出程序再复制整个文件夹即可保留进度。升级时先备份这些个人文件并保留旧目录，避免覆盖丢失。

### 开发者重新构建

    .\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
    .\.venv\Scripts\python.exe -B -X utf8 tools\build_windows.py

每次使用全新的输出与缓存目录，保留旧构建，不执行清空或递归删除。内置资源通过明确允许清单收集，排除data、user_*皮肤、备份、开发日志及凭据。ZIP附带文件散列清单、启动说明及第三方许可。

打包使用[PyInstaller目录模式](https://pyinstaller.org/en/stable/operating-mode.html)，依赖为可替换的独立DLL；[命令选项](https://pyinstaller.org/en/stable/usage.html)使用--onedir、--windowed、--contents-directory .与--icon。
任务栏分组按[Microsoft应用身份接口](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-setcurrentprocessexplicitappusermodelid)在QApplication创建前设置。此次不改桌面快捷方式或系统设置。

# 自定义皮肤与 Windows 便携版

[项目首页](../README.md) · [使用指南](使用指南.md) · [开发指南](开发指南.md)

适用于 Q弹汤圆 1.0。简单导入只需一张 PNG 或 GIF，不必先画四套表情。

## 我应该准备什么文件

| 文件 | 用途 | 建议 |
| --- | --- | --- |
| PNG | 静态角色或表情包 | 透明背景，主体居中，长边 256～512 px |
| GIF | 自己会动的角色 | 短循环、稳定画布、主体位置变化较小，尽量透明背景 |
| 文件夹 / ZIP | 四种状态各有不同外观 | 包含 manifest 及引用的 PNG / GIF |

JPG、WebP、视频和程序文件不能直接导入。纯白底 PNG 可自动移除白底；复杂背景建议事先处理成透明 PNG。尽量裁掉大面积空白。

## 导入、预览与管理

1. 打开 **换装与装修 → 皮肤衣橱**，Lv.3 免费开放，或 50 币提前解锁。
2. 选择本地 PNG / GIF；纯白底 PNG 按需开启自动去白底。
3. 在预览中检查实际外观、GIF、当前风味与挂件对齐。
4. 确认后素材复制到本机，点击新皮肤卡片切换。
5. 衣橱调整大小 0.6～1.5 倍，挂件页调整高度 -30～30 px。

各皮肤分别记住大小和挂件高度；衣橱使用实际待机帧缩略图。自定义皮肤可重命名，移入回收区后可点卡片还原，不物理删除素材。

**GIF 戴皇冠并空翻：** 导入 GIF，达到 Lv.3 后在挂件页点击皇冠，再到特技页点击原地空翻。GIF 动画、呼吸、果冻、挂件、染色和特技共用变换管线。

## 多状态皮肤包

衣橱可导出皮肤包模板。替换图片后，导入文件夹或将整个文件夹压为普通 ZIP：

```text
我的皮肤/
├── manifest.json
├── idle.png
├── happy.gif
├── dizzy.png
└── flat.png
```

```json
{
  "schema_version": 1,
  "name": "我的小伙伴",
  "author": "你的名字",
  "remove_white_background": false,
  "states": {
    "idle": "idle.png",
    "happy": "happy.gif",
    "dizzy": "dizzy.png",
    "flat": "flat.png"
  }
}
```

`idle` 必填，其余状态省略时回退到待机。路径必须为包内相对路径，不能有盘符、绝对路径或 `..`。各状态尽量使用相同画布、相近角色大小和一致脚底位置。导入也会先检查并预览。

## 支持格式与限制

| 检查项 | 当前限制 |
| --- | --- |
| 单个导入文件 | 不超过 20 MiB |
| 包引用素材总量 | 不超过 64 MiB |
| manifest | 不超过 64 KiB |
| 源图 | 最长边不超过 8192 px，单帧不超过 1600 万像素 |
| GIF | 最多 200 帧，累计源画布不超过 6400 万像素 |
| 渲染纹理 | 自动等比限制到最长边 512 px |
| ZIP 条目 | 最多 64 个，拒绝路径越界、链接及异常压缩包 |

全透明、损坏或伪装格式的素材会拒绝。压缩体积与解码预算分别检查，缩小 ZIP 不能绕过限制。包内只放实际需要的图片和 manifest。

## 保存与备份

源码模式复制到 `assets/skins/user_<id>/`，EXE 正式模式复制到稳定应用数据目录的 `skins/`，实际位置见设置。源文件不被改写，自定义素材不上传服务器。

更新或换电脑前，在“数据安全与关于”中备份存档与皮肤。备份含私人素材，不应当作软件安装包公开发送。请使用适合个人欣赏或已取得相应授权的素材。

## 给不会安装 Python 的朋友使用

当前源码发布未附已编译 Windows 包。作者提供或自行构建的便携包应包含 `Q弹汤圆.exe` 和全部依赖。

朋友完整解压后双击 EXE 即可，不需 Python。不要仅发送 EXE，也不要把 GitHub `Source code` 当便携包。关闭窗口只收起到托盘，真正退出使用托盘菜单。桌面图标可为 EXE 创建快捷方式。

EXE 更新可接续稳定应用数据，换电脑用软件内备份恢复。构建与验证命令见[开发指南](开发指南.md#构建-windows-便携版)。当前面向 Windows x64，未提供手机或 macOS 包。

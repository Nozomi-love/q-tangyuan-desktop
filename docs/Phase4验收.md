# Phase 4 本地验收指南

本阶段补齐等级奖励、独立挂件、通用特技和本地皮肤衣橱。核心模块仍为六个，界面与桌宠共用一份养成模型。建议先在独立演示存档中验收，再启动正式模式继续原来的进度。

## 1. 启动独立验收环境

先从现有桌宠托盘选择“退出程序”，在 PowerShell 执行：

    Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
    .\.venv\Scripts\python.exe main.py --demo --dev-mode

终端会输出本次实际演示存档路径，位于 tests/artifacts/demo-时间/save_data.json。请保留这条路径；再次使用 --demo 会创建另一份存档。

双击桌宠或从右键 / 托盘打开主面板，切到【装扮与设置】。向下滚到【好感等级奖励】，勾选“🧪 一键解锁全部等级特权 / 挂件（开发模式）”。它提供本次运行的特权试用，不改成实际 Lv.6；重启后需要重新勾选。调试授予的守护神称号及实际互动统计会保存在当前演示存档。仅在命令行带 --dev-mode 启动时显示此开关，界面中的“开发测试加速”只切换计时，不能代替启动权限。

--dev-mode 默认加快饥饿 / 礼包计时；如果测试皮肤较久，可取消“开发测试加速”或使用“恢复满饥饿”，避免真实饿扁导致特技暂不可用。所有调试操作会影响当前演示进度。

## 2. 最短核心链路：GIF 戴皇冠并空翻

1. 在【皮肤衣橱与自定义导入】点“📂 导入本地图片 / GIF”，选择一张有权使用的本地动态 GIF。正常输入应小于 20 MB、最多 200 帧；较大的长动画可能因总解码量限制而被拒绝。
2. 衣橱应自动切换到新皮肤，GIF 持续播放。拖动、戳一戳和呼吸仍可看到果冻形变。确认导入区一直有本地工具免责声明。
3. 在【独立挂件与周身特效】的“头顶挂件”选择“👑 迷你金皇冠”。皇冠应跟随 GIF 的顶部，不是固定贴在窗口某个绝对位置。
4. 把“挂件垂直微调”滑块分别移到 -30、0、+30 px：负值向上、正值向下，当前数值实时显示；点“归零”回到 0。可同时佩戴墨镜并打开暖心热气。
5. 在【表演特技】点击“🌀 原地 360° 空翻”：宠物跳起并旋转一周、落地 Q 弹，皇冠跟随旋转，GIF 动画继续播放。好感经验 +5，按钮进入 5 秒冷却。
6. 冷却结束，右键桌宠打开“🎪 表演特技”，再次选择空翻。双击仍打开主面板，不触发特技。
7. 勾选固定位置，再表演一次空翻：固定锚点和存档位置保持不变，跳跃 / 旋转通过视觉位移呈现。取消固定后恢复普通桌面物理。
8. 在商城投喂黑芝麻糊或草莓果酱：自定义 GIF 仍可染色、1.2 倍放大 / 显示光点；透明背景不出现矩形色块，挂件继续随动。

特技要求宠物已站稳或处于固定状态；拖拽中、真实饿扁、手动测试饿扁或另一个动作未完成时不会开始。发动失败不发空翻经验，也不扣除冷却。空翻时再次拖拽可接管桌宠，动作结束后不会留下旋转角度或分身。

## 3. 其他挂件与通用特技

| 操作 | 应看到的结果 |
| --- | --- |
| 依次选择呆毛嫩芽、皇冠、樱粉蝴蝶结、不佩戴 | 头顶位置单选；可随时卸下，基础皮肤与自定义皮肤均生效 |

| 挂件状态下戳戳、拖拽晃动、落地压扁 | 挂件随呼吸、缩放、旋转和跳跃一起变化，不与身体脱节 |

| 玩芝麻弹力球 | 黑芝麻小球弹跳 / 顶球互动约 5 秒，宠物开心起跳 |

| 真实饥饿归零后点特技，再快捷投喂白砂糖 | 饿扁时暂不表演；投喂恢复后可继续已解锁动作 |

## 4. 自然等级与提前解锁

取消特权试用开关，按真实好感等级检查权限。原有好感上限仍为 Lv.30；Lv.6 是基础奖励路线的最后一个里程碑，不是养成等级上限。

| 实际等级 | 自动开放的奖励 |
| --- | --- |
| Lv.1 | 白汤圆默认皮肤、基础互动 |
| Lv.2 | 🌱 呆毛嫩芽、🌀 原地空翻 |
| Lv.3 | 👑 迷你金皇冠、本地自定义皮肤导入 |
| Lv.4 | ♨️ 暖心热气 / 星光、✨ Q弹影分身 |
| Lv.5 | 🕶️ 酷盖墨镜、⚽ 芝麻弹力球 |
| Lv.6 | 🎀 樱粉蝴蝶结、称号【✨ 汤圆守护神】 |

要独立验收 50 币入口，可再建一份 --demo 存档，并暂时不启用特权试用。Lv.1 初始 100 币时，导入按钮锁定；点击“50 糯米币提前解锁”后余额变成 50，导入按钮可用。重复调用不会重复扣费。余额不足 50 时按钮不可用；自然达到 Lv.3 时免费获得导入权限，不会再扣这 50 币。提前开放衣橱不会一并开放皇冠，皇冠仍按 Lv.3 或特权试用判断。

## 5. PNG、动作包与模板

### 单张 PNG

导入白底 PNG 时勾选“自动移除纯白背景”，应只在内存 / 渲染链路处理边缘连通近白底，保留主体内部白色。取消勾选后，应保留图片自带的白底。透明 PNG 保留 Alpha；原始文件不会被覆盖。全透明、损坏或格式不匹配的图片会被拒绝。

单图模式的四种交互状态共用同一张图片 / GIF，通用形变照常生效。需要不同表情时使用动作包。

### 导出并导入模板

点“📄 导出皮肤包模板”，选择目标位置；程序在其中创建一个新的“汤圆皮肤模板-时间”文件夹，包含 manifest.json、README.txt 和 idle / happy / dizzy / flat 四张示例 PNG，不覆盖已有文件夹。先直接导入模板文件夹验证，再替换为自己的合法素材。

最小配置示例：

    {
      "schema_version": 1,
      "name": "我的多状态桌宠",
      "author": "本地作者",
      "remove_white_background": false,
      "states": {
        "idle": "idle.gif",
        "happy": "happy.png",
        "dizzy": "dizzy.gif",
        "flat": "flat.png"
      }
    }

idle 必填，其余三个状态可以省略，缺少状态回退 idle。路径使用包内相对路径，状态文件只允许 PNG / GIF。名称和作者作为普通文本显示，不执行脚本或富文本内容。

分别测试“导入动作包文件夹”和“导入 ZIP 动作包”。ZIP 可包含位于根目录或单层包目录中的 manifest.json；四个状态也可以混用 PNG 与 GIF。点击后短暂 happy，拖拽显示 dizzy，调试归零显示 flat，恢复后切回正常状态；各状态都能保留挂件、Buff 和特技。

## 6. 成就与持久化

首次导入 / 切换自定义皮肤，或首次穿戴一件挂件，应触发二阶成就《灵魂注入》。头顶提示达成，成就页可领取 100 币及称号【百变星君】；领取后不能再次发奖，可在状态页切换佩戴。

选择一张自定义皮肤、皇冠及非零 offset_y，勾选固定位置并拖到易观察的位置，再从托盘安全退出。用第 1 步终端输出的真实演示路径重新启动，例如：

    .\.venv\Scripts\python.exe main.py --resume-demo 'D:\Codex\Q弹汤圆\tests\artifacts\demo-实际时间\save_data.json' --dev-mode

上面的 demo-实际时间须替换为本次真实目录。不能再加 --demo；--resume-demo 只接受 tests/artifacts 内已有的 save_data.json。

应恢复已选自定义皮肤、养成 / 背包 / 成就 / 称号、挂件选择和偏移、固定状态和位置。特权试用是运行期设置：如果实际等级仍低于挂件要求，需要重新勾选“一键解锁全部等级特权 / 挂件”才重新显示这些挂件；已选自定义皮肤会恢复播放。实际已到 Lv.3 的皇冠与衣橱权限无需试用开关，正常启动后自动恢复。单次特技和其冷却属于运行期动作，不会在重启时重放。

正式模式仍使用 D:\Codex\Q弹汤圆\data\save_data.json。旧版本存档首次正式保存会先备份原字节，再升级到版本 4，保留窗口、旧进度及未知字段；本阶段测试使用隔离存档，不替用户迁移正式存档。导入素材复制到 `assets/skins/user_<uuid>/`；移动原始文件后仍能播放沙箱副本。如果沙箱素材缺失或损坏，使用默认外观兜底、保留原选择并提示，可从衣橱重新导入或选择白汤圆。

## 7. 异常输入与本地安全检查

| 校验 | 限制 / 预期 |
| --- | --- |
| 单文件 | 最大 20 MiB（界面简称 20 MB），包括 ZIP 本身及包内单文件 |
| 动作包 | 仅支持 Stored / Deflate 压缩；最多 64 个条目，总展开内容不超过 64 MiB；大于 1 MiB 的 ZIP 条目压缩比超过 200 倍时拒绝 |
| manifest | 最大 64 KiB；只接受受支持的状态和本地相对路径 |
| 图片源尺寸 | 最长边不超过 8192 px，单帧 / 画布不超过 1600 万像素 |
| 渲染纹理 | 大图等比限制最长边 512 px，原始素材不被重写 |
| GIF | 最多 200 帧，累计源画布像素不超过 6400 万；校验结构、帧完整性与解码结果 |
| 路径 | 拒绝绝对路径、盘符、..、不安全分隔符、系统保留名、符号链接 / 目录联接及重解析点 |
| 内容 | 拒绝损坏、全透明 PNG、图片扩展名与实际格式不一致、加密 / 异常 ZIP 等输入 |

可以选择一张超限文件或损坏图片验证界面反馈。导入失败应出现原因提示，当前外观、经验与余额保持不变；不执行包内程序，不把素材写到沙箱之外。路径穿越、超限和恶意归档由自动化测试构造验证，测试产物保留在 tests/artifacts/，不要通过手工编辑正式存档做破坏性测试。

自定义素材、正式 / 演示存档、备份和测试产物均被 Git 忽略，不上传 GitHub。免责声明描述的是本地渲染工具的数据行为；用户仍需自行确认素材使用授权。

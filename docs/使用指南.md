# Q弹汤圆 2.0 使用指南

[项目首页](../README.md) · [版本说明](2.0版本说明.md) · [开发指南](开发指南.md)

这是围绕LOL赛事与社区二创制作的本地互动游戏。房间、桌宠共享同一只汤圆和一份进度。

## 启动与退出

GitHub 2.0发布提供源码和正式素材，没有附EXE；`Source code` 与 `Code → Download ZIP` 需要Python，安装步骤见[开发指南](开发指南.md#从源码启动)。收到作者另行构建的完整Windows便携ZIP时，完整解压后双击 `Q弹汤圆.exe`，无需Python。

| 操作 | 结果 |
| --- | --- |
| 关闭主窗口 | 收到托盘，继续在线 |
| 双击托盘 | 打开房间主页 |
| 再次启动同一存档 | 唤醒已有房间与桌宠，不多开 |
| HUD或托盘桌宠开关 | 显示/隐藏桌宠，状态记忆 |
| 托盘右键“退出程序” | 保存并真正退出 |

更新前必须从旧进程的托盘退出；否则再次双击可能只是唤醒旧版。

## 日常、互动与音效

房间左键戳戳、右键摸头；桌宠单击戳戳、双击回主窗口、按住移动拖拽。静置约12～25秒后自然看窗外、闻饭、打盹、伸懒腰、哼歌或小跳。房间隐藏时本地演出暂停。

“急咯急咯”、满饱喂食、落地、陀螺和乐器各有对应台词或演出。“我们会创造新的历史”用于换上应援皮肤；“太阳升起了，大脑空空”出现在上午低频日常。二创表达不当作选手逐字采访记录。

在线奖励自动到账，**不会再定时响“叮”**；自动升级或成就达成也不自动响铃。主动戳戳掉币、手动领奖、投喂、八音盒和风铃等仍有相应音效。HUD、右键和托盘共用静音开关，重启记忆。

## 装修与特技

家具在 **商城 → 家居家具** 购买，再到 **背包 → 装修** 点击布置。不同槽位独立，同槽位一次一件。初始自带云朵软垫、朴素小木碗和温馨奶酪屋。

空调360币，使用墙面槽，和挂画/挂钟互换；点击房内空调开关，状态会保存。暖灯可点亮/关闭，挂钟指向电脑时间，风铃有摆动与响声。食盆放在侧边茶几，避免和角色自身黄碗重叠。

**背包 → 特技** 或桌宠右键“表演特技”：空翻、影分身、弹力球、迪斯科按等级开放。绕屏滚一圈在商城花360币永久学习，约12秒绕工作区一周再回原位，冷却20秒，途中点击可结束；不占用双击。反向闪现360币永久学习，演出2.6秒、冷却12秒；自由桌宠短闪不超过60逻辑像素，固定时本体不移动。两款商城特技不产生额外好感或金币。

## 桌宠与位置

HUD和托盘可显示/隐藏桌宠；单击戳戳、双击打开房间，拖拽松开后带惯性落回当前工作区底边。

- 右键固定当前位置，可停在任意选定位置；取消固定恢复重力。
- 固定与非固定都记住所在屏幕与位置，重启按工作区比例恢复。非固定在空中保存时，恢复后继续下落。
- 静止靠边的呼吸、压扁不会累计把汤圆向内推；真正拖拽、抛投与辣油奔跑仍会移动。
- 找不到时从托盘“重置回主屏幕右下角”；这是主动重置，会改变位置。
- 房间的溜达与演出不改桌宠固定坐标；忙碌表情不再把房内横坐标切回中央。房间演出结束先站定，静置1.5秒后平滑回地毯；点击中断保留当帧实际位置，再自然归窝。

## 存档备份与更新

到 **设置 → 数据安全与关于** 看版本和真实数据目录。

| 模式 | 位置 |
| --- | --- |
| 源码正式 | 项目data/save_data.json；旧个人素材在assets/skins/user_*/ |
| EXE正式 | 系统稳定应用数据目录，在设置查看完整路径 |
| --demo | tests/artifacts/下的新独立演示档 |

“一键备份存档与皮肤”导出带校验的ZIP；备份包括旧私人素材，请自己保存。恢复前会备份现有进度并校验文件，内置皮肤只保存归属与ID，不重复存八张大图。

升级2.0前先备份并从托盘退出旧版。源码保留原数据文件夹，EXE使用稳定应用数据目录；换电脑或跨源码/EXE迁移使用软件内备份恢复。存档schema仍为5，币、等级、家具、成就和旧个人资源不会因产品版本2.0重置。

## 常见问题

**关窗后还在线？** 关窗只是托盘常驻，真正退出用托盘菜单。

**为什么下到的ZIP没有EXE？** 当前Release发布源码；免环境便携包须另行构建并完整解压。

**为什么吉他不能用？** 换上飞行桃团后再赠送。

**怎么上传图片？** 2.0已移除该入口，衣橱使用内置皮肤；旧素材兼容保留。

**为什么不再定时响铃？** 自动在线奖励已静音，余额仍增加。

**特技不能开始？** 先恢复饱食、落稳，结束拖拽并等待冷却；同一时间只能一个显式特技。

**重新打开还是旧版？** 从旧托盘真正退出，再启动更新后的源码或重新构建的EXE。

**任务栏还是Python图标？** 退出旧入口后重开；若固定过Python快捷方式，取消旧固定，再固定当前汤圆窗口。

**支持手机或macOS？** 当前实测与构建面向Windows x64，没有其他平台发行包。

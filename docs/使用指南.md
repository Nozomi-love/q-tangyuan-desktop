# Q弹汤圆 1.0 使用指南

[项目首页](../README.md) · [自定义皮肤](自定义皮肤与便携版.md) · [开发指南](开发指南.md)

你可以只在房间里养汤圆，也可以显示桌宠；两种方式共享同一份进度。

## 启动与退出

**拿到 Windows 便携包：** 将整个 ZIP 完整解压，打开 `Q弹汤圆` 文件夹，双击 `Q弹汤圆.exe`。无需 Python；请保留全部依赖文件，不要仅复制 EXE，也不要在压缩包中运行。需要桌面入口时，为 EXE 创建快捷方式。

**拿到 GitHub 源码：** 当前仓库及 1.0 Release 没有附编译包；`Code → Download ZIP` 和 `Source code` 都是源码。按[开发指南](开发指南.md#从源码启动)安装环境并运行。

| 操作 | 结果 |
| --- | --- |
| 关闭主窗口 | 收起到系统托盘，程序继续在线 |
| 双击系统托盘图标 | 打开汤圆的家 |
| 再次启动同一存档 | 唤醒已有小窝与桌宠，不重复开实例 |
| 右上角桌宠按钮 / 托盘显隐菜单 | 显示或隐藏桌宠，选择会记住 |
| 托盘右键 → 退出程序 | 保存并真正退出 |

托盘图标也可能在任务栏的隐藏图标区域。更新前请从托盘退出旧进程，再启动新版本。

## 认识小窝

![1.0 小窝实际运行画面](images/v1.0-home.png)

左上角是名字、等级、饱食、好感与称号，名字旁按钮可以命名。右上角是糯米币、风味倒计时、静音和桌宠开关。房间随电脑时间呈现昼夜，可点击灯具，挂钟按真实时间走动。

底部喂养架显示已有食物；五个导航打开同屏抽屉，操作时房间保持可见：

| 导航 | 用途 |
| --- | --- |
| 小屋主页 | 收起抽屉，完整查看房间 |
| 背包与投喂 | 使用已有食物与礼物、查看统计、佩戴称号 |
| 商城 | 购买食物、礼物、家具和永久特技 |
| 换装与装修 | 皮肤、挂件、特技、等级奖励与家具布置 |

内容较多时在抽屉内部滚动，“回房间”收起抽屉。

## 日常互动与音效

在房间里左键戳汤圆，右键摸头。桌宠支持单击戳戳、双击打开小窝、按住拖拽；拖拽和双击不算有效戳戳。

无操作约 12～25 秒后随机看窗外、溜达、闻饭、打盹伸懒腰、哼歌或小跳。主动操作会优先打断日常；房间隐藏时房内演出暂停。

房间右上角、桌宠右键菜单与托盘菜单共用同一个静音状态，重启后保留。投喂、戳戳、获得币、八音盒和风铃有相应音效。

## 养成规则

| 数值 | 正常模式规则 |
| --- | --- |
| 初始 | 100 糯米币、80 饱食度、Lv.1、当前级 0 经验 |
| 饱食 | 0～100；每 288 秒减 1，满值到零为累计在线 8 小时 |
| 饿扁 | 不死亡、不扣好感；投喂食物后恢复，送礼不恢复饱食 |
| 好感 | Lv.1～30；每级所需经验为当前等级 × 500，只增不减 |
| 戳戳 | 饱食 ≥50 时 +2 好感，否则 +1 |
| 摸头 | +3 好感，10 秒冷却 |
| 在线收益 | 每 90 秒自动入账 10～20 币与 5 好感，无需领取 |
| 随机掉币 | 每天前 20 次戳戳，每次 35% 概率 +2 币 |
| 升级 | 自动奖励 30 币，满 Lv.30 不再积累经验 |
| 成就 | 达成后前往成就页领取一次性币与称号 |

程序留在托盘仍计在线时间；完全退出期间不补算饥饿、收益或事件。

## 食物与投喂

路径：**商城 → 食品与礼物 → 食物**。“购买”放进背包，“购买并投喂”立即使用。背包或底部喂养架使用库存，不再次扣币。

| 等级 | 食物 | 价格（币） | 饱食 | 额外效果 |
| --- | --- | ---: | ---: | --- |
| 1 | 温开水 | 30 | +15 | 无 |
| 1 | 白砂糖 | 30 | +15 | 与右键快捷投喂同数值 |
| 2 | 黑芝麻糊 | 75 | +35 | 深灰芝麻色，1.2 倍体型 |
| 2 | 草莓果酱 | 75 | +35 | 粉红色与上升光点 |
| 2 | 宇治抹茶粉 | 75 | +35 | 抹茶绿色 |
| 3 | 桂花酒酿 | 135 | +65 | 无 |
| 3 | 变态辣油 | 135 | +65 | 红色，前 12 秒小跑或固定位置跺脚 |

食物不增加好感，饱食最高 100。投喂时图标飞向汤圆，随后咀嚼、粒子与实际恢复量飘字；满饱仍会消耗食物，请按需使用。

普通风味 60 秒，同种刷新，不同种替换；基础食物不清除现有风味。辣油在桌宠自由模式沿任务栏小跑，固定时原位跺脚。

## 装修、挂件与特技

在 **商城 → 家居家具** 购买，再到 **换装与装修 → 小窝装修** 点击已拥有的卡片布置。主题、地毯、墙面、角落、食盆茶几、窗边、伴宠分别使用槽位，同槽位一次一件。

初始自带温馨奶酪屋、云朵软垫和朴素小木碗。高级奖励家具随等级开放，不能提前购买。默认汤圆自带黄碗，额外食盆放在侧边茶几；暖灯可直接点击开关，风铃布置后可点击响铃。

**挂件装扮**中点击已解锁图标穿戴，选择“不佩戴”或相应开关收起。高度可调 -30～30 px。**皮肤衣橱**中选择外观并调整 0.6～1.5 倍大小，每个皮肤分别记住大小和挂件高度。导入、重命名和可还原回收区见[皮肤指南](自定义皮肤与便携版.md)。

**特技与等级奖励**中点击已开放特技，或使用桌宠右键“表演特技”。双击桌宠仍用于打开小窝。

“绕屏滚一圈”在 **商城 → 特技图鉴** 花 360 币永久学习，约 12 秒沿当前屏幕工作区绕行并返回原位；冷却 20 秒。房内表演同样回到实际起点，点击可提前结束。

## 桌面宠物

右上角桌宠按钮或托盘菜单显示 / 隐藏桌宠，与房间共享进度、皮肤、挂件与风味。

- 单击戳戳，双击打开小窝。
- 按住移动可拖拽，松开后带惯性落到当前工作区底边。
- 右键“固定当前位置”可停在选定位置，并记住固定状态与坐标。
- 找不到桌宠时，从托盘重置回主屏幕右下角。

房间溜达不改变已固定桌宠的位置。屏幕计算采用 Qt 逻辑像素；本机已验证 Windows 150% 缩放，其他多屏组合仍需实际试用。

## 存档、备份与更新

进入 **成就与设置 → 游戏设置 → 数据安全与关于** 查看真实目录与操作入口。

| 模式 | 数据位置 |
| --- | --- |
| EXE 正式模式 | 系统稳定应用数据目录，完整路径见设置 |
| 源码正式模式 | 项目 `data/save_data.json`，用户皮肤在 `assets/skins/user_*/` |
| `--demo` | 新建 `tests/artifacts/demo-时间/` 独立存档 |

日常进度自动保存。换电脑或源码 / EXE 互转：旧版点“一键备份存档与皮肤”导出 ZIP，从托盘退出，启动新版，点“从备份恢复”并确认，检查名字、余额、家具和皮肤。

恢复前自动备份当前进度；坏文件不会替换进度，同 ID 不同内容的皮肤分配新 ID 并保留现有素材。备份含个人素材，请自己保存。

EXE 更新可完整解压到新目录并接续同一应用数据；源码更新请保留原项目的数据与用户皮肤。1.0 命名调整不会重置旧进度。

## 常见问题

**关闭窗口后为什么还在运行？** 关闭只收起到托盘，退出用托盘菜单。

**只在房间里养可以吗？** 可以，关闭右上角桌宠开关即可。

**双击后还是旧版？** 同存档会唤醒已有进程，先从旧托盘退出，再启动新版。

**下载的 ZIP 为什么没 EXE？** GitHub 的源码包需要 Python；便携包应包含 EXE 及依赖。

**为什么变扁或不能表演？** 检查饱食度，饿扁需食物恢复，礼物不能恢复。开发模式还可手动测试外观。

**为什么不能导入？** Lv.3 免费开启，或先付 50 币。文件问题见[限制](自定义皮肤与便携版.md#支持格式与限制)。

**为什么食物没加好感？** 1.0 食物负责饱食，礼物与互动负责好感，满 Lv.30 停止累积。

**任务栏还是 Python 图标？** 退出旧入口；若固定过旧 Python 快捷方式，取消旧固定，再固定当前汤圆窗口。

**没有声音？** 检查静音、Windows 应用音量与输出设备；音效失败不影响养成。

**支持手机 / macOS 吗？** 当前便携构建面向 Windows x64，其他平台未完成发布与验证。

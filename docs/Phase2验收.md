# Phase 2 本地验收

项目：D:\Codex\Q弹汤圆。更新代码后先从旧桌宠菜单退出，避免两个进程同时写同一存档。

## 启动

在 PowerShell 中运行：

    Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
    .\.venv\Scripts\python.exe main.py --demo

演示模式新建独立存档，初始 100 币、饥饿 80、Lv.1，终端会显示保存路径；不会修改 data/save_data.json。正式使用去掉 --demo 即可，会恢复之前的固定位置并升级旧存档。

## 按顺序验收五个场景

1. 戳一戳掉币：先右键查看初始值，再左键单击汤圆。每次饱腹点击 +2 EXP；每天前 20 次点击有 35% 概率 +2 币并显示“戳出 2 枚糯米币”。概率事件不保证每次出现。拖拽不加点击数，也不加互动经验。
2. 挂机礼包：保持程序运行 90 秒；可在“调试与外观”开启加速缩至每 10 秒，或用“立即生成拾币气泡”直接检查外观。点击发光气泡，应 +10～20 币、+5 EXP；点击汤圆也能领取并附带本次戳戳收益。再次点击不能重复领同一礼包。再生成一次，不领取，30 秒后应自动入账。完成后关闭加速，以免验收过程中饥饿下降太快。
3. 真实饿扁：在“调试与外观”点“饥饿值归零”。查看菜单为 0/100，贴图变 flat、高度压至约 40%，仍能拖动但点击不跳；经验与等级不减少。静置 45 秒会再次出现委屈提示。单独开关“手动测试饿扁”不能解除真实饥饿。
4. 投喂恢复：选“快捷投喂白砂糖”，应扣 10 币、饥饿由 0 变 25、+10 EXP，立即回弹并恢复体型。测试开关开启时，成功投喂也会将其关闭。余额不足 10 时该操作禁用，不能透支。
5. 好感升级：先调试恢复满饥饿，查看当前 EXP，继续戳到等级 ×50 的阈值。Lv.1 从 0 起通常 25 次饱腹点击达到 Lv.2；已有经验时次数更少。应自动保留多余 EXP、+30 币，显示高亮升级气泡；自由模式连跳三次，固定模式原位连续 Q 弹。之后正常关闭再启动，等级、余额、位置均应恢复。

上述互动会相互累加经验，所以验收时余额除指定操作外也可能包含随机掉币或升级奖励。菜单可随时查看实际总值。

## 其他检查

- 摸摸头：+3 EXP 与开心台词；10 秒内按钮显示冷却并禁用，结束后恢复。
- 顶部和侧边：固定汤圆后拖到屏幕顶角，触发气泡。气泡应完整留在工作区，顶部空间不足时出现在下方；无边框宠物画布不会裁切独立气泡。
- 气泡跟随：出现礼包时拖动汤圆，气泡应跟随；升级提示结束后继续显示待领礼包。
- 饿扁零惩罚：不喂食可以一直保留，等级与经验不会倒退。
- 退出保存：未领礼包的金额 / 剩余时间与每日计数会保存；重启不重复赠送初始 100 币，也不按关闭时长扣饥饿。
- 跨天：每日判定次数与掉落次数按系统当地自然日重置，累计点击 / 投喂 / 挂机秒数保留。自动测试注入日期验证此行为，不修改系统时间。

## 自动验证范围

51 项 Phase 1 回归与 44 项 Phase 2 测试，覆盖概率边界、跨天、零饥饿、消费、满级、多级经验、礼包一次领取 / 超时、计时余量、迁移备份、未知字段、过期会话、真实鼠标事件、气泡淡入淡出和负坐标工作区。

Windows 原生脚本 tests/verify_phase2_native.py 在两个独立进程中验证：旧存档升级、20 次戳戳、真实 10 秒加速礼包、点击气泡、饥饿归零、投喂恢复、升级奖励，以及重启恢复养成 / 位置 / 未领礼包。脚本保存实际渲染截图并检查干净退出。所有测试仅操作 tests/artifacts/ 中的存档。

本机原生验证为单屏 150% 缩放；多台实体显示器尚未实测，负坐标和边缘位置使用模拟测试。正式 90 秒阈值与 30 秒超时由模型时间推进验证。

# Phase 3 本地验收

项目：D:\Codex\Q弹汤圆。核心六模块：main.py、models.py、pet_engine.py、pet_window.py、save_manager.py、dashboard.py。

## 启动与独立存档

先从旧版托盘菜单退出，再在 PowerShell 中运行：

    Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
    .\.venv\Scripts\python.exe main.py --demo --dev-mode

每次 --demo 创建一份新的独立存档，终端会打印完整路径；正式 data/save_data.json 不受影响。--dev-mode 开启饥饿 / 礼包加速，且新风味持续 15 秒；正常模式风味 60 秒。辣油行为两种模式均为前 12 秒。

保留终端打印的实际存档路径，退出后可继续同一份演示进度：

    .\.venv\Scripts\python.exe main.py --resume-demo 'D:\Codex\Q弹汤圆\tests\artifacts\demo-实际时间\save_data.json'

将示例中的“实际时间”替换为终端显示的目录；需要继续加速时追加 --dev-mode。--resume-demo 仅允许已有的 tests/artifacts 内 save_data.json，不能指向正式存档，也不能与 --demo 同时使用。正式日常运行不带这些演示参数。

## 推荐验收顺序

1. 主面板唤出与隐藏：双击桌宠，检查四个标签页；这两下不应增加戳戳次数、经验或掉币。关闭右上角只隐藏，桌宠与托盘继续运行；菜单“打开主面板”能再次显示。关闭主面板后，从托盘“退出程序”应彻底退出。
2. 单击与初始奖励：间隔约 0.25 秒戳一次，在成就页领取《Q弹初体验》的 30 币；右键摸头，领取《温柔摸头》的 30 币。双击判定窗口为 200ms，普通单击稍后确认。拖拽不算点击。
3. 买进背包：在免费商城购买温开水，余额 -5，饥饿 / 经验暂不变，背包出现 ×1；去状态页点“投喂 / 使用”，数量 -1、饥饿 +10（最多 100）、经验 +5，不再扣币。领取《第一口甜》的 50 币。先领取这些奖励足够体验所有风味。
4. 黑芝麻：购买并投喂黑芝麻糊，直接扣 35 币、饥饿 +40、经验 +20，不留库存；观察深灰色调与 1.2 倍体型，碗底锚点不漂移。拖拽、倾斜、点击回弹时，应完整绘制，不被悬浮窗画布裁切。
5. 草莓与抹茶：分别购买并投喂；草莓呈柔粉色并冒上升光点，抹茶呈绿色。五官可辨，透明背景没有色块。不同风味替换，同种风味刷新倒计时；温开水等基础食物不清除当前风味。
6. Buff 到期与图鉴：观察状态页倒计时；加速模式 15 秒后恢复原色 / 原体型，正常模式 60 秒。体验三个不同口味后，《百味汤圆》显示 3/3；领取 100 币后才解锁【美食鉴赏家】，点击“佩戴称号”，状态页和下拉框同步。重复投喂同一口味不重复计数。
7. 辣油自由模式：先取消固定，再投喂辣油，观察当前屏幕任务栏上方左右小跑和轻跳，碰边反弹；12 秒后停止行为，染色继续到总 Buff 到期。拖起来仍能正常接管，不会强行脱离鼠标。
8. 辣油固定模式：固定在屏幕中部，再投喂辣油，观察原地快速 Q 弹跺脚；固定锚点不应改变。狂奔过程中开启固定也应立即停止平移，取消固定后可恢复剩余行为。
9. 三个隐藏彩蛋：按下面的表逐项触发；检查头顶吐槽 / 成就播报与图鉴进度。正常关闭再继续演示存档，确认成就只能领取一次。
10. 保存恢复：背包留两份食物，佩戴已解锁称号，开启一种风味并固定位置后安全退出；用 --resume-demo 继续。币、等级、库存、已领成就、称号、位置和风味剩余时间应恢复；关闭期间不扣饥饿、不推进 Buff。每日统计继续沿用同一天记录。

加速模式会同时加快饥饿与礼包；需要慢慢观察界面时，可在设置页关闭加速再投喂。切换模式只改变后续新风味的时长，不追溯修改已经生效的倒计时。

每个首次达成都播报“解锁成就，可前往主面板领奖”。同时达成多项时排队播报，升级 / 眩晕反馈有更高优先级，不丢失其他成就提示。达成和领取分开：只有点击领取才发币 / 解锁称号，已经领取的按钮禁用，重启也不会重复发奖。

可按三阶过滤图鉴；未达成条目显示实时进度，已解锁称号可在状态页自由切换。旧版已有点击 / 投喂 / 等级记录会用于补解锁对应成就，奖励仍需手动领取；旧版未记录的收礼 / 摸头 / 抛落等新增统计从 0 开始，不推算历史。

# Q弹汤圆 1.0 版本说明

[项目首页](../README.md) · [使用指南](使用指南.md) · [开发指南](开发指南.md)

- 对外版本：**1.0.0**。
- 定版日期：2026-10-23（北京时间）。
- 定位：Windows 本地宠物养成小窝与可选桌面宠物。
- 发布内容：源码、默认资源、现行指南与开发记录。

## 已完成功能

温馨房间、紧凑 HUD、同屏抽屉、昼夜光影、灯与挂钟；命名、饱食、Lv.1～30、自动在线币和 12 成就；7 食物、4 礼物、风味与互动演出；16 家具及等级奖励；独立挂件、粒子与程序特技；PNG / GIF / manifest 包导入、预览、真实缩略图、单皮肤配置及管理；可隐藏桌宠与位置固定；单实例、自动存档、备份恢复和独立演示模式。

收录最新陀螺原地横向自转、结束无残留，以及绕屏从实际位置出发并返回的修复。

## 版本名称与兼容

用户在本日将当前完成功能统一确定为首个对外 **1.0**。过去 Phase / V2 为内部开发阶段标记，历史文档与测试文件名保留。

本次保留全部功能和玩家进度，不降低存档 schema，不改变 Qt 应用身份、数据目录、任务栏或单实例通信身份。旧的本地 EXE 仍可能显示 v2.0；源码需退出旧进程再启动，EXE 需重新构建，不会因仓库改版而原地改变旧文件。

## 下载与平台

当前 GitHub 1.0 发布提供源码，没有附编译好的 Windows 包。`Source code` 与 `Code → Download ZIP` 是源码快照，需要 Python。

仓库提供 Windows x64 构建脚本；作者可提供完整便携 ZIP，收到便携包无需 Python。构建和验证见[开发指南](开发指南.md#构建-windows-便携版)。不把个人皮肤或存档放进公开包。

Windows x64 为当前实测平台；手机、macOS 和其他平台未提供发行包。出游、明信片与来访伙伴等后续设想暂缓，不属于 1.0 已实现功能。

# 开发日志

时间使用北京时间（Asia/Shanghai）。本文件记录需求、决策、已完成实现、实际验证和未完成事项；Git 提交记录对应引入 Git 之后的实际变更。

## 2026-10-16：架构确认

- 产品为本地离线的桌面陪伴宠物与免费养成游戏，默认白汤圆。
- 确定 Python 3.10+、PySide6、Qt Widgets、QPainter、后续 GIF 使用 QMovie。
- 采用共享数据模型、桌宠悬浮窗、养成主面板和系统托盘。
- 用代码形变实现呼吸、Q 弹回弹和抛投；皮肤内容与变换分离，后续饰品使用独立图层。
- 明确零惩罚：饥饿归零饿扁但不死亡、不扣好感；好感只增不减。
- 分四阶段实施，核心模块规划为 main、models、save_manager、pet_engine、pet_window、dashboard。
- 双击用于主面板，空翻将使用独立菜单入口，避免交互冲突。

## 2026-10-16：Phase 1 完成

交付：
- 透明、置顶、无边框的 Tool 桌宠窗口及系统托盘。
- 四张表情 PNG 的文件名约定与缺图备用绘制。
- 底部中心锚点、反相呼吸、阻尼弹簧回弹和轻跳。
- 5 逻辑像素拖拽阈值、±18° 倾角、最近 0.12 秒采样的释放惯性。
- 基于显示器 availableGeometry 的重力、边缘反弹及落地压缩。
- 复位、饿扁测试、热加载与安全退出。

实际修复：
- 拖拽时倾角变化导致包围盒越界：在每个子步重新限制边界。
- 鼠标捕获丢失导致永久悬空：处理 UngrabMouse 并结束持有状态。
- 150% 缩放下整数窗口原点产生取整偏移：改用 Qt mapFromGlobal 计算绘制锚点。

验证：
- 30 项行为测试通过，包含负坐标工作区和 30/60/120/144 Hz。
- Windows、Python 3.12.6、Qt 6.8.3、单显示器 150% 缩放下原生启动通过。
- 两秒冒烟执行 120 次动画更新，窗口与托盘可用。
- 置顶/Tool/透明分层、托盘动作与退出后的计时器停止验证通过。
- 多块物理显示器和其他操作系统尚未实测。

说明：以上需求与实现发生在引入 Git 之前，依据当时的实际交付记录补录；最初 Git 提交时间为本次实际初始化时间，没有伪造过去的提交时间。

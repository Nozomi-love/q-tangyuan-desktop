# 在线静音与位置复位修复（本地开发版）

本次覆盖自动入账的金币音、房间礼物/表情/特技切换坐标、桌面靠边回弹偏移，以及非固定桌宠重启恢复。奖励数值、保存进度与现有静音开关沿用。

## 启动

从托盘选择退出，再双击项目的 `Q弹汤圆.lnk`。该入口已核实指向项目 Python 与 `main.py`。原有便携 EXE 本轮未重建。

开发验收建议使用独立演示档，在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 main.py --demo --dev-mode
```

## 手动检查

1. **在线静音**：保持总静音关闭。正常在线奖励每90秒、开发加速每10秒自动到账；余额仍增加，后台不再“叮”。自动升级或达成挂机成就也不会响铃。主动戳戳/投喂、赠送八音盒以及手动领取成就奖励仍有对应音效，可用总静音关闭。
2. **房间原位**：让汤圆溜达到偏右处，依次送八音盒、星星、花束、陀螺；使用飞行桃团皮肤还能送吉他与麦克风。演出结束留在本次起点，花束有平滑回程，不再走回固定中央坐标。
3. **中断不复跳**：花束演出中戳一下、摸头、投喂，或者启动绕屏/空翻。汤圆从当下位置响应，旧演出不会稍后把它拉回去。连戳触发眩晕、测试饿扁或拖动桌宠时，房间汤圆的横坐标也不应突然跳到中央。
4. **桌面靠边**：取消固定，把桌宠放到屏幕左侧/右侧边缘附近，停稳后连续点击几次；挤压可能暂时向内让位，回弹后不应越戳离边缘越远。真正抛投仍保留惯性，辣油仍会奔跑。
5. **重启记忆**：固定桌宠后拖到新位置，退出再启动，位置与固定状态应恢复。取消固定，等它落稳再退出，重开应保持所在屏幕和横向位置；若保存时仍在空中，会从保存位置继续下落。点击“重置桌宠位置”仍会主动回到主屏右下角。

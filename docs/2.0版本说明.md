# Q弹汤圆 2.0 版本说明

- 版本：v2.0.0；日期：2026-10-23（北京时间）。
- 平台：Windows x64；Python 3.10+ / PySide6。
- 本次提供：源码、正式队标皮肤、插画、配置、截图和现行指南。

## 产品内容

以英雄联盟赛事、选手和社区二创为内核，养成与桌宠作为载体。加入八款队标版皮肤与圈内语境道具，保留原有同屏房间、物理和成长系统。梗资料按来源与证据区分，不将二创台词标作新采访原声。

## 新增

- 赤笠熊猫、霓虹猫团、飞行桃团、柴犬白团、黑金虎团、元气橘团、赤焰凤团、薄荷电竞熊；Lv.2/3/4/5/6/8/10/15免费或每款900币提前永久购买。

- Lv.10称号世一汤、Lv.20金汤良圆，以及用户指定的两句新对白。

## 界面调整

- 导航统一为小屋主页、背包、商城、成就与等级奖励、设置。
- 背包收纳投喂与赠礼、换装（皮肤/挂件/称号）、装修、特技。
- 成就图鉴与等级奖励在同一抽屉；领取称号后跳转背包佩戴。
- 移除自定义皮肤导入与管理入口，旧档/旧素材保留底层兼容。
- 空调只叫空调，皮肤只用昵称；无风味时隐藏原味标签。

## 修复与安静体验

- 六种礼物演出结束/取消统一清场，不留下地面小图标。
- 礼物回到各自起点，花束平滑回程；用户互动或显式特技打断后不恢复旧演出。
- 眩晕、饿扁与按住等状态不再把房内宠物切回中央横坐标。
- 桌面靠边呼吸、点击压扁、落地回弹不再累计永久内移；真实抛投和奔跑仍保留。
- 固定和非固定位置都在重启时恢复原屏幕位置，非固定继续重力。
- 自动在线入账及连带升级不播放金币提示音；主动互动掉币和手动领奖仍有音效。

## 兼容与资源

保留存档schema5与应用身份，不重置玩家进度。内置皮肤和个人user_*目录分离：正式八款随仓库发布，个人形象、预览、参考下载、运行存档、备份、凭据、测试证据和本机二进制不上传。

八款正式图各为一张基础PNG，不宣称已绘制32张表情差分。默认四图、QMovie兼容底层、独立挂件与风味变换沿用。素材与队徽为同人使用，不代表官方授权产品。

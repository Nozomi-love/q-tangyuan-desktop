## 启动与体验

先从托盘退出旧进程，再从项目源码启动；二次启动会唤醒已在运行的旧进程。

```powershell
Set-Location -LiteralPath 'D:\Codex\Q弹汤圆'
.\.venv\Scripts\python.exe main.py
```

独立演示档（不改正式进度）：

```powershell
.\.venv\Scripts\python.exe main.py --demo --dev-mode
```

1. **商城→食品与礼物**：食物子页购买新品并投喂，观察飞入、咀嚼、冰雾/木塞/饭峰/爆米花；饱食增加，好感不增加。先喂辣油再喂可乐，颜色与奔跑应解除。
2. **商城→礼物**：购买或购买并赠送骰子、绳子、登山镐、场记板；观察随机三段体型、进退拉扯、三阶跳跃插旗、三幕分身。每件约7秒，结束清场并回到本次起点；中途戳它或发动空翻，不能跳回旧坐标。
3. **商城→战队与装扮**：购买帽子/背包，再去背包→换装→挂件穿戴；调整高度，切换内置皮肤。辣油下风扇加速、空调下变缓；橘子帽眩晕时橘瓣展开；兜帽完成空翻后亮边；纳尔耳帽随特技展开；背包小旗轻摇，登峰后短暂点亮。
4. **商城→家居家具 / 背包→装修**：买并布置电竞椅、训练假人、战术大屏、录音棚。点击电竞椅看晃动；点击假人看靠近三次轻碰再回程；连续戳、喂、送礼，大屏只保留最近三项；录音棚显示吸音板，乐器演出时有柔和录音氛围。
5. 退出再重开，核对余额、库存、新装扮所有权、挂件偏移与家具布局。下架/重做不清空老进度，不改饱食衰减和在线收入。

开发模式设置里的“礼物演出预览”加入4款新礼物，可零消费看完整动画。用“全部特权试用”测试新挂件，关闭试用后未购买物不再生效；永久购买测试可使用托盘调试里的“立即结算在线糯米币”积累演示币。

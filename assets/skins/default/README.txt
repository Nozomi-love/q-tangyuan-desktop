四张透明 PNG 的约定

本目录是正式默认皮肤位置。当前不附带外部图片，缺图时自动绘制圆形备用外观。

idle.png   默认待机，同时作为基础外观
happy.png  点击后显示 0.8 秒
dizzy.png  拖拽期间显示
flat.png   测试饿扁开启时显示

建议：四张图使用相同构图和比例，透明背景，256×256 或 512×512。
程序裁掉透明边，按统一身体外框归一化，并以底部中心进行形变。
flat.png 的最终扁平高度统一由程序控制到约 40%。
某张缺失时回退到 idle.png，idle.png 缺失时回退到圆形。
放好图片后选择托盘/右键菜单“重新加载表情 PNG”，无需重启。
更多说明与验收步骤见项目根目录 README.md。

默认元宝汤圆表情包

本目录现有四张用户提供的原始 PNG，全部保留原文件名与字节。
expressions.json 将它们映射为 idle、happy、dizzy、flat。

14_01_36.png：待机
14_01_42.png：点击开心，持续 0.8 秒
14_01_47.png：拖拽眩晕，包含星星
14_01_53.png：饿扁/难受

原始图片为白底 RGB；程序只在内存中去除与边缘连通的白底，
保留轮廓内部白色身体。以最大连通主体对齐碗底、等比缩放，
眩晕的星星不参与主体缩放。饿扁高度由代码压至约 40%。

也支持放入标准名 idle.png / happy.png / dizzy.png / flat.png；
标准名优先于映射名。透明 PNG 保留原有透明通道。
更换图片或 expressions.json 后，选择菜单“重新加载表情 PNG”。
修改程序代码后应先重启桌宠。

原图 SHA-256 与来源说明见项目 docs/素材记录.md。
